What is a servlet container ?

A Servlet Container is software that manages the complete lifecycle of Servlets.

Responsibilities

• Load Servlets
• Create Servlet Objects
• Call init()
• Call service()
• Call destroy()
• Manage Sessions
• Handle HTTP Requests
• Handle HTTP Responses

Examples

• Apache Tomcat
• Jetty

====================================================================
18. WHAT IS A SERVLET?
=====================================================================

Definition

A Servlet is a Java class that runs inside a Servlet Container and
processes HTTP Requests to generate Dynamic Responses.

A Servlet can

• Read Form Data
• Validate User Input
• Connect Database
• Perform Calculations
• Manage Sessions
• Generate HTML
• Generate JSON

=====================================================================
19. WHY DO WE NEED SERVLETS?
=====================================================================

Without Servlets

• Java cannot directly handle browser requests.
• No standard mechanism to process HTTP requests.

Servlets provide

• Request Handling
• Response Generation
• Session Management
• Database Integration
• Dynamic Web Content

Web Server: Understands HTTP and serves static files like HTML, CSS, and images,
 but cannot run Java code natively.
Servlet Container: Provides the Java runtime environment required to execute servlets 
and dynamic JSP pages.
